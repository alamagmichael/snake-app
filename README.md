# Neon Snake

A modern browser-based Snake campaign with 30 handcrafted levels. Each level introduces a new obstacle pattern, target score, and speed curve for a compact arcade progression.

## Features

- 30 named levels with unique layouts and increasing target counts.
- Neon glassmorphism interface with live score, target, and progress feedback.
- Keyboard controls with Arrow keys, WASD, and Space for pause/resume.
- Touch-friendly directional pad for smaller screens.
- Static frontend that can be served by any local web server.

## Run locally

```bash
npm run start
```

Then open <http://localhost:4173> in your browser.

## Check syntax

```bash
npm run check
```
